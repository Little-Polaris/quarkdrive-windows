# 夸克网盘挂载与自动启动

普通夸克驱动 → OpenList → 本地 WebDAV 容量适配 → Rclone → Windows 网络盘符。默认 Q:，支持读写，并显示账户真实总容量及剩余容量。

另一台机器安装：完整解压 Release ZIP，双击 Install.cmd，或运行 Deploy.ps1，按向导完成账户配置和服务注册。所需软件已在包内。

注册后由 Windows 开机自动启动，意外退出自动恢复，无需每次手动启动。服务运行于 LocalSystem；盘符供本机登录用户读写，在资源管理器“此电脑”中使用。
部署向导可以取消“注册为 Windows 服务”；该模式由当前用户的后台进程挂载，下次使用时运行 scripts/Start-Quark.ps1。

需要手动控制时，运行 scripts/Start-Quark.ps1 或 scripts/Stop-Quark.ps1。服务注册后脚本控制这三个服务；控制服务时需要 Windows 管理员授权。也可在 Windows 服务管理器中操作。

OpenList 管理地址：<http://127.0.0.1:5244>，用户名 admin，密码保存在本机 runtime/admin-password.txt。Cookie 失效时，在“存储 → /Quark”中更新 Cookie。

## 数据与缓存

- scripts/：安装、服务控制、容量适配与验证脚本。
- docs/：依赖软件、迁移步骤与使用说明。
- bin/：Release 包内的程序、运行环境、安装器、许可和源码归档。
- runtime/：本机凭据、数据库、日志和缓存，不包含在 Release 包或 Git 中。

文件关闭后从本地缓存上传到夸克。停止服务或关机前应等待上传完成；脚本检测到待上传文件时会拒绝停止。缓存目标上限 2 GB，打开的大文件可能超过该值。非正常退出后，下次启动沿用原缓存，继续处理待上传文件。

账户容量缓存 60 秒，资源管理器也可能缓存显示；Windows 剩余空间按文件系统块大小取整。速度与上传限额受夸克账户权益和网络影响。

scripts/Test-QuarkRW.py 可实测上传、修改、重命名、读取和删除，并从云端核对内容；每次创建唯一测试目录并清理本次文件。
