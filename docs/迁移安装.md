# 夸克网盘 Windows 服务安装包

适用：64 位 Windows 10 / 11。此包只含脚本和说明；先按 `dependencies.md` 安装 Python、WinFsp，并准备 OpenList、Rclone、WinSW。不需要任何 pip 包，也不需要 PowerShell 7。

## 在另一台机器安装

1. 将 ZIP 完整解压到本机固定目录，例如 `C:\QuarkDrive`。不要直接在压缩包中运行；目录所在磁盘应在开机时可用。
   按 `dependencies.md` 准备软件，将程序放到约定的 `bin/` 子目录或加入 PATH。
2. 浏览器打开 <https://pan.quark.cn> 并登录自己的夸克账户。
3. 按 F12 打开开发者工具，在“网络 / Network”中刷新页面；选择 `drive.quark.cn` 的请求，从“请求标头 / Request Headers”复制 `Cookie` 的完整值。
4. 双击 `Install.cmd`，选择空闲盘符（默认 Q:），粘贴 Cookie，点击 Install services。
5. Windows 弹出管理员授权提示时点“是”。安装成功后打开资源管理器“此电脑”。

之后服务随 Windows 自动启动，不需要登录后再运行脚本。开机延迟自动启动可能需要一两分钟；联网和账户验证完成后盘符可用。
WinFsp 需预先安装；如果其安装器要求重启，重启后再运行本包的安装向导。
安装包不含原机器的 Cookie、账户数据库、密码、日志或缓存。

## 服务及操作

Windows 服务管理器中有三个服务：

| 服务名 | 显示名称 | 用途 |
| --- | --- | --- |
| QuarkOpenList | Quark - OpenList | 连接夸克网盘，提供读写接口 |
| QuarkQuota | Quark - Capacity WebDAV | 本地 WebDAV，补充真实容量 |
| QuarkMount | Quark - Network Drive | 挂载盘符 |

服务按依赖顺序启动，启动类型为“自动（延迟启动）”，意外退出后自动重启。
服务以 LocalSystem 运行，盘符供本机已登录的 Windows 用户读写；不开放局域网访问。
本地接口仅监听 `127.0.0.1:5244` 和 `127.0.0.1:5245`。同一台机器只安装一套；需要改目录或盘符时，先卸载服务，再重新安装。

Cookie 失效时，打开 <http://127.0.0.1:5244>，以 `admin` 登录，密码在 `runtime/admin-password.txt`；在“存储 → /Quark”更新 Cookie。运行目录包含登录信息，应留在本机。

双击 `Uninstall.cmd` 移除这三个服务。卸载保留本地配置、密码和缓存，也保留 WinFsp，网盘文件不受影响。卸载前关闭正在编辑的文件并等待上传完成；有待上传文件时脚本会停止卸载。
安装失败时查看 `runtime/install-result.json` 和 `runtime/logs/`。盘符或 5244、5245 端口被占用时，先处理占用后再安装。

## 文件写入与容量

支持上传、新建目录、编辑、重命名、移动和删除。文件先写入本机缓存，关闭后上传；关机或停止服务前等待上传完成。缓存目标上限 2 GB，打开的大文件可能超过该值，需预留足够本机空间。
容量来自当前夸克账户，缓存约 60 秒，资源管理器可能稍后刷新。速度与限额受夸克账户权益和网络影响。
