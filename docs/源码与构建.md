# 源码与构建

本项目的源码就是仓库内的 PowerShell / Python 脚本。它们采用 AGPL-3.0-only，Release 附带相同脚本及许可全文。

OpenList 官方程序保持原样。Release 的 `bin/sources/` 附带以下对应版本的上游源码归档，包含各自的 README、许可和构建脚本：

- `OpenList-v4.2.6.tar.gz`：后端源码、Go 模块定义及 `go.sum` 依赖锁定。
- `OpenList-v4.2.6-with-dependencies.tar.gz`：后端及 `go mod vendor` 收集的对应依赖源码、版权和许可文件。
- `OpenList-Frontend-v4.2.6.tar.gz`：前端源码、依赖定义与构建脚本。

解压后按照上游构建说明准备 Go / Node 等构建工具。后端 `go.mod` 指定的工具链为 Go 1.27.0，构建入口为 `build.sh`；完整后端源码包可用 `-mod=vendor` 使用随附依赖。前端按其 `package.json` 和 `build.sh` 构建。重建对应版本时使用 v4.2.6 的前端，保持后端和前端版本匹配。

源码地址：

- <https://github.com/OpenListTeam/OpenList/tree/v4.2.6>
- <https://github.com/OpenListTeam/OpenList-Frontend/tree/v4.2.6>
